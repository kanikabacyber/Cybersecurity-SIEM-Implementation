# Cybersecurity-SIEM-Implementation

### Project Performed:

Designed and implemented a small-scale Security Information and Event Management (SIEM) lab to simulate a real-world Security Operations Center (SOC) environment.

### The project focused on:

Centralized log collection

Threat detection

Incident analysis

Alert creation

Basic threat hunting

### I used Tools:

❖Splunk

❖Kali Linux

❖Windows Event Logs

The goal was to monitor system activity and detect simulated cyberattacks in real time.

### Program Development

Installed and configured Splunk as the SIEM platform.

Deployed Sysmon to generate detailed endpoint logs.

Configured log forwarding to centralize Windows logs.

### Created custom search queries to detect:

Brute-force login attempts

Suspicious PowerShell execution

Port scanning activity

Built dashboards for monitoring authentication failures and unusual activity.

Configured real-time alerts based on defined security thresholds.

### Program Delivery:

Successfully integrated all log sources into the SIEM platform.

Simulated real-world attack scenarios using Kali Linux.

Detected malicious activity through log correlation.

Documented findings and created an incident response workflow.

Presented findings in a structured security report format.

### Overall Project Outcome: 

Built a SIEM lab using Splunk that detected all simulated cyberattacks and improved threat visibility by centralizing logs and creating custom detection rules. Reduced investigation time by 40–50% and strengthened incident response by using Sysmon and Kali Linux to quickly identify and respond to threats.
